# Process-and-CPU-scheduling-simulations
Mini projects from CS 3200: Operating Systems

##Midterm Project:
This shows how processes are generated and how they move through different states. 
It includes number of context switches, number of events, for a fixed number of processes.
It logs every time a process changes state.

##Final Project v1:
This is an extension of the midterm project but includes First Come First Serve and Shortest Job First scheduling algorithms.
At the start of the simulation, the user chooses what shceduling algorithm they prefer.
The simulation displays a table of information at the start, the logging of each event in the middle and then a final table of results.
This project includes the I/O request, disk queue and network queue, which changes the completion and waiting time.

##Final Project v2:
The same as v1 but without the I/O request or disk and network queues. This makes the final times more accurate and the summary results 
are the same as they would be if you did the exercise on paper.
